# cub3D

`cub3D`は、[Raycasting](https://lodev.org/cgtutor/raycasting.html)技術を用いて、迷路を3Dで探索するリアルタイムグラフィックプロジェクトです。伝説的なゲーム「Wolfenstein 3D」にインスパイアされています。

## 概要

このプログラムは、`.cub`ファイルで記述されたマップ情報を読み込み、それを3Dグラフィックスとしてウィンドウに描画します。プレイヤーは迷路内を自由に歩き回り、壁に囲まれた世界を一人称視点で探索できます。

## 機能

*   **Raycastingエンジン**: 2Dのマップデータを元に、リアルタイムで3Dの視点を描画します。
*   **マップのパース**: `.cub`ファイルから壁のテクスチャ、床と天井の色、マップレイアウトを読み込みます。
*   **プレイヤー操作**: 迷路内を前後左右に移動し、視点を回転させることができます。
*   **テクスチャマッピング**: 壁の各面に異なるテクスチャを適用します。
*   **エラーハンドリング**: 不正なマップファイルや設定が与えられた場合に、適切にエラーを報告します。

## 使用技術

*   **言語**: C
*   **グラフィックライブラリ**: [minilibX](https://github.com/42Paris/minilibx-linux)

## セットアップと実行

### 1. リポジトリのクローン

```bash
git clone https://github.com/your_username/cub3D.git
cd cub3D
```

### 2. ビルド

`Makefile`を使ってプロジェクトをコンパイルします。

```bash
make
```

### 3. 実行

コンパイル後に生成される実行可能ファイル `cub3D` に、引数としてマップファイル（`.cub`）を渡して実行します。

```bash
./cub3D maps/basic_testmap.cub
```

テスト用のマップが `maps/` ディレクトリにいくつか含まれています。

## 操作方法

| キー          | アクション       |
|---------------|------------------|
| `W`           | 前へ進む         |
| `S`           | 後ろへ下がる     |
| `A`           | 左へ移動         |
| `D`           | 右へ移動         |
| `←` (左矢印キー) | 左に視点回転     |
| `→` (右矢印キー) | 右に視点回転     |
| `ESC`         | プログラムを終了 |

## マップファイル（`.cub`）のフォーマット

マップファイルは、以下の要素で構成されます。

1.  **方角テクスチャ**: 北・南・西・東の壁に対応するテクスチャ画像（`.xpm`）のパス。
    *   `NO ./path/to/north_texture.xpm`
    *   `SO ./path/to/south_texture.xpm`
    *   `WE ./path/to/west_texture.xpm`
    *   `EA ./path/to/east_texture.xpm`

2.  **床と天井の色**: RGBカラーコード（0-255）。
    *   `F 220,100,0` (床の色)
    *   `C 225,30,0` (天井の色)

3.  **マップレイアウト**: `1`（壁）、`0`（空間）、`N`/`S`/`E`/`W`（プレイヤーの初期位置と向き）で構成されます。マップは必ず壁（`1`）で囲まれている必要があります。

    ```
    1111111111
    1000N00001
    1011001001
    1000000001
    1111111111
    ```
